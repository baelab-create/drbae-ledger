# 닥터배 프로페셔널 파트너 관리대장

배랩 공인 프로페셔널 파트너가 납품처(에스테틱 샵)를 월 1회 이상 멘토링하고 기록하는 관리대장.
화면은 GitHub Pages, 데이터는 Firebase Firestore(`baelab-ledger`).

- `index.html?k=키` — 파트너 화면. 링크 키로 자기 대장만 읽고 씀 (로그인 없음)
- `admin.html` — 본사 화면. 구글 로그인(본사 계정만). 파트너별 현황, 중복 알람, 주문 동기화, 링크 발급, 월말 자료
- `shared/core.js` — 판정·매칭 로직 (브라우저와 Node 공용)
- `sync/sync.mjs` + `.github/workflows/sync.yml` — drbae-map `data.csv`를 읽어 주문을 파트너 대장에 자동 반영 (하루 3회)
- `firestore.rules` — Firestore 보안 규칙 (콘솔에 붙여 넣어 적용)

## 규칙 요약
- 거래처 추가 = 관리 시작. 등록일에 "거래처 등록" 대면 기록이 자동 생성되어 그 달은 이행 처리
- 매달 소통 1회 이상 → 이행. 부재·거부 시도 2회 이상 → 이행 인정
- 3개월 무주문 거래처는 삭제하지 않고 "주요 관리 대상"으로 표시. 제외는 파트너가 직접
- 정산율·정산액은 저장하지 않음. 월말 자료 탭의 CSV(이행 거래처 + 주문 합계)로 외부 계산
- 주문 매칭 키: 대표샵명·옵션의 샵 상호명·수취인명 → 별칭 → 주소. 미매칭은 본사 화면에서 별칭 연결
